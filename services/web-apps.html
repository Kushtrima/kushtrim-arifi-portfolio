Web apps

When a website is not enough, when people need accounts, payments, records and an admin side, I draw the screens in Figma and build them in Laravel or React. One is a case study here: a membership and donations app for a mosque community in Switzerland.

What you get

  • Accounts and roles

    Members, administrators, and a clear line between what each of them may see and do.

  • Payments that clear

    Stripe and TWINT, invoices, recurring billing, and a record of every transaction that can be searched later.

  • An admin side people use

    Dashboards, search, filters and exports, built for the person who has to do this every week rather than for a demo.

  • Reminders that send themselves

    Automatic mail when a payment falls due or a membership is ending, so nobody has to keep a list.

  • Records you can stand behind

    Audit logs, backups, and member data handled with the care the GDPR expects.

  • Drawn before it is built

    Every screen in Figma first, so the flow is settled before a line of code is written.

How it goes

  • Understand

    Who uses it, how often, and what they do today instead. Usually a spreadsheet, and the spreadsheet tells you a lot.

  • Design

    The screens in Figma, including the empty states and the awkward cases, not only the happy path.

  • Build

    Laravel or React, tested with real data and real amounts of it.

  • Launch and hand over

    You get the Figma file and the code, and a walk through the admin side with whoever will run it.

Where it has been built

  • Membership and donations

    En-Nur — member and admin dashboards, Stripe and TWINT payments, automated reminders

  • And a CRM

    Designed and delivered at MONUN AG: multi-member accounts and roles, recurring billing, invoicing, Stripe payments, admin dashboards and audit logs

Where the practice comes from

  • 2024 — today

    At MONUN AG: a CRM designed and delivered end to end, and continuous deployment that cut release time by 40%

  • Stack

    Laravel, PHP, MySQL and PostgreSQL on the server; React, TypeScript, JavaScript in the browser

  • Practice

    Lint and formatting enforced, 700+ issues cleared, JavaScript defects down about 45%
